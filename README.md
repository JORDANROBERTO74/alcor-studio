# Alcor Studio

Landing page for Alcor Studio, an independent creative studio for brands with
somewhere to go.

## Tech stack

- **Next.js** (App Router) + **React 19**
- **Tailwind CSS v4** with a custom design system
- **shadcn/ui** primitives + **base-ui**
- **@vercel/analytics**

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev` — start the development server
- `pnpm build` — production build
- `pnpm start` — serve the production build

## Internationalization

The site ships in English (default) and Spanish. The language is detected from
the browser, persisted in `localStorage`, and can be switched from the
navigation bar.

## Deploy

Deployed on [Vercel](https://vercel.com).
